## 0.19.8

Release of the Ectype Framework on Thunderstore. Adds the class framework (registration of playable classes from a JSON manifest, gene-tree injection, ability wiring), loot-table registration, enemy and character statuses, field-backed stats, the HUD ability bar and mutator-list safety for clients missing a session mutator. The package includes the API documentation file EctypeFramework.xml beside the DLL.
